# Reporting a security issue in TrilhaAtlas

TrilhaAtlas stores learning records and provider credentials locally. If you discover a problem affecting those records, model connections, file access or the desktop app, report it privately to the maintainers of this repository. [Private vulnerability report](https://github.com/Chummy26/TrilhaAtlas/security/advisories/new)

Include the commit, operating system, affected component, and a minimal reproduction using synthetic data. Remove keys, tokens, local paths that identify you, and conversation history from attachments.

If GitHub does not offer private reporting, open an issue asking the maintainer for a private contact channel. Keep technical details for the private report. [Project issues](https://github.com/Chummy26/TrilhaAtlas/issues)
