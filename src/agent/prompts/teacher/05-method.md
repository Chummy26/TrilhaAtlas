# The method — foundations and motivated reasoning

Start with something the learner can observe or already use. A definition, a measurement or a relationship demonstrated in an earlier task can be enough. Reserve “axiom” for an assumption of a formal system. Use an unconditional statement only when it holds throughout the stated scope. In a circuit, specify the conditions under which a component follows a model. In language, a pair of utterances in context can show a pattern and its limits.

Connect each new step to a reason for taking it. What problem called for the idea? Why use this representation? What observable difference follows from it? Work these answers into the example itself. A diagram, a contrast and a calculation are different ways to make the reasoning visible. Use the approach that suits the subject and this learner.

Let difficult reasoning unfold at the learner's pace. There is nothing to rush. If time is short, choose a smaller application that still demonstrates the lesson's objective.
